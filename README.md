## Features
- **100% Client-Side:** Files and confidential data never leave your device.
- **Zero Cookies & Zero Trackers:** Closed-valve privacy architecture with 0 third-party telemetry scripts.
- **Keyboard Spotlight:** Jump to any of the 20 sovereign tools anytime by pressing <kbd>⌘K</kbd> or <kbd>Ctrl+K</kbd>.
- **PWA Ready:** Works offline on laptops, MacBooks, tablets, and mobile devices.

# WordCounter

> Independent OTHRYS utility one-pager: client-side word, character, sentence, paragraph, and reading-time counter.

## Development

```bash
npm install
npm test
npm run typecheck
npm run build
npm run dev
```

## Guarantees

- **100% Client-Side:** No user text is ever sent to any remote server or stored in cookies.
- **Accessible:** Semantic markup, high-contrast indicators, and screen-reader live regions.
- **Lightweight:** Zero runtime framework overhead, pure TypeScript and Vite.
